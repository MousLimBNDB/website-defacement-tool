📋 n8n Connection Setup Guide & Troubleshooting:

  1. HTTP Method: In your n8n Webhook Node, set HTTP Method to POST.
  2. Test Mode: If using a Test URL (contains /webhook-test/), click "Listen for Test Event" inside n8n before clicking Test Webhook.
  3. Production Mode: If using a Production URL (contains /webhook/), toggle your n8n workflow switch to ACTIVE.
  4. Network Address: If n8n runs in Docker/VM, use your server IP (e.g. http://172.17.0.1:5678/...) instead of localhost.

Available Payload Fields:

  • target_id - Database ID of monitored target
  • target_name - Human readable name of the site
  • target_url - Full URL of target site
  • similarity_score - Canvas expansion similarity (0.0 to 1.0)
  • is_defaced - Boolean flag confirming defacement
  • confidence - AI model diagnostic confidence (0-100%)
  • change_type - Classification (Defacement, Update, Error)
  • analysis_summary - Diagnostic text explanation
  • screenshot_path - Path to current audit screenshot
  • diff_path - Path to visual diff image
  • popup_path - Path to isolated popup screenshot (if captured)
  • timestamp - ISO timestamp of audit check
